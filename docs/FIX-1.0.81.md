# 1.0.81: план профиля не зацикливается на настройках панелей

После применения профиля «2 файла ждут применения» появлялись снова при каждой
синхронизации, хотя настройки панелей уже были применены в браузере.

## Причина

Настройки `dsh-polish` и `dsh-cards` — браузерные (`panelVisibility`): host пишет
их в очередь `browser-settings.pending.json`, клиент применяет в localStorage и
подтверждает `{ applied: true }`. Но после применения он не отправлял новый
снимок localStorage, поэтому host хранил пустой `browser-settings.json` и при
следующем плане снова видел расхождение с зеркалом.

## Исправление

- `BrowserSettingsBridge`: после `applyBrowserSettings(pending)` клиент отправляет
  `{ current: readBrowserSettingsSnapshot() }` (актуальные значения), затем
  `{ applied: true }` (очистка очереди). Host сохраняет снимок, и план профиля
  сходится: локальный и зеркальный хэши совпадают.

## Проверки

```
node --check client.js
node --import ./test/setup.mjs --test test/*.test.mjs   → 421/421
node test/client-smoke.mjs                              → OK
```

## После перезапуска

Открыть DSH один раз: мост применит очередь и пришлёт снимок; план профиля
должен очиститься (`плана нет`).
