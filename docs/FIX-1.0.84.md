# 1.0.84: фантомные режимы «локальная» чистятся сами

После восстановления/синхронизации в `session-modes.json` периодически
появлялись записи для id, которых нет в сторе: панель показывала «локальных 23»
при одной реальной локальной сессии.

## Исправление

- Новый `pruneSessionModes(home)` в `lib/session-modes.mjs`: удаляет режимы для
  сессий, которых нет в `~/.dsh/sessions`.
- `enforceLocalOnly` (подготовка к каждой синхронизации) вызывает его после
  применения объявлений — фантомы не накапливаются.
- Объявления «локальная навсегда» по-прежнему не удаляются: чистим только режимы.

## Проверки

```
node --check lib/session-modes.mjs lib/cloud-copy.mjs
node --import ./test/setup.mjs --test test/*.test.mjs   → 456/456
```

Новый тест в `test/modes-phantom.test.mjs`: реальная сессия остаётся локальной,
режим несуществующей — удаляется.
