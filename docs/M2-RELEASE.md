# M2: группы субагентов и удаление «везде» — 1.0.71

Версия `1.0.71` закрывает M2 из плана `18-ПЛАН-РАБОТ.md`: атомарная группа
«родитель + субагенты», удаление «везде» без воскрешения, очередь отложенных удалений,
UI групп.

## Групповая синхронизация

- Родитель и все его потомки — одна единица обмена: pull импортирует сначала родителя,
  затем детей; ребёнок не импортируется, пока родителя нет (`waitingParent`).
- Удаление родителя убирает группу целиком на всех устройствах: дети уходят в карантин
  с `reason: children`, копии не воскресают после `fetch + reset`.
- Сирота (ребёнок без родителя в источнике) импортируется с `reason: orphan`
  и **не удаляется** автоматически.
- `reconcileLocalDeletions()` повторно применяет активные метки к локальным копиям
  после сброса/восстановления каталога; `made-local` не трогает.
- Счётчики в отчёте: `groups`, `children`, `groupsDeleted`, `orphans`; строка
  «групп: N, субагентов: M, сирот: K».

## Удаление «везде» и очередь

- Локальная команда удаления ставит метки на родителя и всех потомков
  (`expandDeletionIds`), метки уезжают ближайшим push.
- Офлайн-удаление: `enqueueDelete(home, ids)` — одна операция в outbox с `payload.ids[]`,
  повторяется при flush; `cloudCopy`-удаления не смешиваются.
- `/api/dsh-sync/prune` отвечает «удалено в карантин вместе с N субагентами»,
  в отчёт добавлены `childrenQuarantined`, `childrenMissing`, `orphanIds`.

## UI

- «Сессии и режим»: субагенты вложены под родителем, свёрнуто, бейдж «+N»
  (`aria-expanded`), линия связи; у сироты бейдж «сирота» с подсказкой;
  счётчик «групп: N, субагентов: M[, сирот: K]» в шапке карточки.
- «Удалённые»: «+N», «сирота», «Восстановить группу (N)» — одна кнопка
  восстанавливает родителя и детей (идемпотентно).
- Диалог удаления: «Вместе с этой сессией будут удалены субагенты: N…».
- Восстановление по id любого участника расширяется до корня группы
  (`restoredGroup{root,size,ids,restored}`).
- Вёрстка: чипы/кнопки по гайду (32 px, radius 10), адаптив 640 px, скролл.
